# ARX X5 快速测试流程（ROS2 Humble）

> 适用于 X5-2023。默认：左臂=can1(/dev/arxcan1)，右臂=can3(/dev/arxcan3)。

## 0. 前置检查
```bash
# 看到 arxcan1/arxcan3 说明 udev 规则生效
ls -l /dev/arxcan*

# 看到 can1/can3 说明 CAN 口已启动
ip link show can1
ip link show can3
```

## 2. 单臂测试（左臂 / 右臂）

### 2.1 启动 CAN
```bash
# 左臂
sudo slcand -o -f -s8 /dev/arxcan1 can1
sudo ip link set can1 up

# 右臂
sudo slcand -o -f -s8 /dev/arxcan3 can3
sudo ip link set can3 up
```

### 2.2 启动控制节点
```bash
cd /home/solegua/ARX_X5-main/ROS2/X5_ws
source install/setup.bash
ros2 launch arx_x5_controller open_single_arm.launch.py
```

**注意**：`open_single_arm.launch.py` 读取配置文件：
`/home/solegua/ARX_X5-main/ROS2/X5_ws/src/arx_x5_ros2/arx_x5_controller/config/single_arm.yaml`

- 测左臂：`arm_can_id: can1`
- 测右臂：把它改成 `arm_can_id: can3`

### 2.3 键盘控制
```bash
source /home/solegua/ARX_X5-main/ROS2/X5_ws/install/setup.bash
ros2 run arx_x5_controller KeyBoard
```

键盘映射（小步长）：
- `i`：重力补偿
- `r`：回零
- `w/s`：x +/- 0.005
- `a/d`：y +/- 0.005
- `方向键↑/↓`：z +/- 0.005
- `n/m`：roll +/- 0.05
- `.` / `l`：pitch +/- 0.05
- `,` / `/`：yaw +/- 0.05
- `o/c`：夹爪开合 +/- 0.15

## 3. 双臂同时（两套控制 + 两个键盘）
> 不要同时运行 `arx_can1.sh` 和 `arx_can3.sh`，它们会 `pkill slcand` 互相干扰。

### 3.1 启动两条 CAN
```bash
sudo slcand -o -f -s8 /dev/arxcan1 can1
sudo ip link set can1 up

sudo slcand -o -f -s8 /dev/arxcan3 can3
sudo ip link set can3 up
```

### 3.2 启动两个控制节点（不同 topic）
```bash
# 左臂
ros2 run arx_x5_controller X5Controller --ros-args \
  -r __node:=arm_l \
  -p arm_can_id:=can1 \
  -p arm_sub_topic_name:=arm_l_cmd \
  -p arm_pub_topic_name:=arm_l_status \
  -p arm_end_type:=0

# 右臂
ros2 run arx_x5_controller X5Controller --ros-args \
  -r __node:=arm_r \
  -p arm_can_id:=can3 \
  -p arm_sub_topic_name:=arm_r_cmd \
  -p arm_pub_topic_name:=arm_r_status \
  -p arm_end_type:=0
```

### 3.3 两个键盘分别控制
```bash
# 控左臂
ros2 run arx_x5_controller KeyBoard --ros-args \
  -r __node:=kb_l \
  -r arm_cmd:=arm_l_cmd

# 控右臂
ros2 run arx_x5_controller KeyBoard --ros-args \
  -r __node:=kb_r \
  -r arm_cmd:=arm_r_cmd
```

> 哪个终端有焦点，键盘就控制哪条臂。

## 4. 停止与清理
```bash
# 停止控制节点/键盘：Ctrl+C

# 关闭 CAN 接口
sudo ip link set can1 down
sudo ip link set can3 down
sudo pkill slcand
```
