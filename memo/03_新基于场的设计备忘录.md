版本: Final

用途: 程序实现与论文写作的统一依据

## 1. 总体目标

学习一个形态 (morphology) 条件化的末端位姿空间隐式场：

$$\hat{s}_{\theta}(x;\mathcal{M}): SE(3)\times\mathcal{M}\rightarrow\mathbb{R}$$

其中 $x=(p,R)\in SE(3)$ 为末端位姿（位置 $p\in\mathbb{R}^{3}$, 姿态 $R\in SO(3)$），$\mathcal{M}$ 为机械臂形态（关节/连杆/关节限位等）。

**要求:**

- $\hat{s}_{\theta}(x;\mathcal{M}) > 0$ 表示可达 (feasible) 。
    
- $\hat{s}_{\theta}(x;\mathcal{M}) < 0$ 表示不可达 (infeasible) 。
    
- 零等值面 $\{x:\hat{s}_{\theta}(x;\mathcal{M})=0\}$ 逼近可达集合边界 $\partial\mathcal{R}(\mathcal{M})$ 。
    
- 梯度 $\nabla_{x}\hat{s}_{\theta}$ 在边界邻域可用于将不可达点沿“最小综合调整量”方向拉回可达区域（并支持任务阶段权重变化的推理策略）。
    

---

## 2. 可达性定义与三层限制 (Oracle)

### 2.1 形态与关节空间

- **形态 $\mathcal{M}$**: 包含运动学树、关节类型/轴、父子变换、连杆参数、关节限位等 。
    
- **关节变量**: $q\in\mathbb{R}^{n}$ 。
    
- **关节限位集合**: $\mathcal{Q}_{lim}:=\{q\in\mathbb{R}^{n}|q_{min}\le q\le q_{max}\}$ 。
    
- **前向运动学**: $FK_{\mathcal{M}}(q)=x\in SE(3)$ 。
    

### 2.2 自碰判定

定义二值函数 $SC(q)\in\{0,1\}$：

- $SC(q)=1$ 表示该关节构型不自碰 。
    
- $SC(q)=0$ 表示存在自碰 。
    

### 2.3 可达集合 $\mathcal{R}(\mathcal{M})$

对末端位姿点是否可达采用三层限制（必须同时满足）：

1. **存在 IK 解**: $\exists q\in\mathbb{R}^{n}$ 使得 $FK_{\mathcal{M}}(q)=x$ 。
    
2. **在关节限位内**: $q\in\mathcal{Q}_{lim}$ 。
    
3. **不自碰**: $SC(q)=1$ 。
    

因此可达集合定义为：

$$\mathcal{R}(\mathcal{M}):=\{x\in SE(3) \mid \exists q: FK_{\mathcal{M}}(q)=x, q\in\mathcal{Q}_{lim}, SC(q)=1\}$$

### 2.4 可达性判别 Oracle $\mathcal{O}(x;\mathcal{M})$

定义 Oracle 输出 $\mathcal{O}(x;\mathcal{M})\in\{0,1\}$：

$$\mathcal{O}(x;\mathcal{M})=\mathbb{I}[x\in\mathcal{R}(\mathcal{M})]$$


**实现层面**: 必须在工程上固定求解器类型、多初值策略、迭代上限、收敛阈值、关节限位处理方式以及自碰检查配置（详见第 9 节）16。

## 3. 位姿参数化与统一度量 (长度-角度量纲对齐)

### 3.1 姿态的李代数坐标

对姿态使用对数映射，定义 6 维局部坐标：

$$\xi = \log(R) \in \mathbb{R}^{3}$$


$$z(x) = \begin{bmatrix} p \\ \xi \end{bmatrix} \in \mathbb{R}^{6}$$

**工程注意**:

- $\log(R)$ 在接近 $\pi$ 的区域存在不连续性，实际实现中应保证扰动与边界搜索不跨越该不连续面。
- 若出现跨越风险，可限制旋转扰动幅度或使用最小角度对数映射。


### 3.2 加权度量 (固定 $\lambda$, 归一化单位)

为统一位置（长度）与姿态（弧度）的影响，对位置进行尺度归一化，并在归一化单位下固定权重 $\lambda$。

1. 位置归一化: 令 $L_{ref}$ 为参考长度尺度（默认取该形态的“总臂长”尺度）。定义归一化位置：
    
    $$\tilde{p} := p / L_{ref}$$
    
2. **姿态李代数坐标**: $\xi = \log(R) \in \mathbb{R}^{3}$ 20。
    
3. 归一化度量: 对 $x=(p,R)$ 采用 6 维局部坐标 $z(x)=[\tilde{p}; \xi]$，并定义：
    
    $$d(x_1, x_2)^2 := ||\tilde{p}_1 - \tilde{p}_2||_2^2 + \frac{1}{\lambda^2} ||\xi_1 - \xi_2||_2^2$$
**参数含义**:

- $\lambda$ 的单位为 **(normalized length)/rad** 。
    
- 物理含义：姿态变化 1 rad 在度量上等价于位置变化 $\lambda$ 个“归一化长度单位”。
    
- **默认值**: $\lambda = 0.15$ (即 $1 \text{ rad} \approx 0.15 \times \text{臂长}$) 。

**单位约定**:

- 所有几何阈值（$\varepsilon, \delta, m, t_{max}$）均在归一化空间定义。
- 若工程实现使用米单位，必须先除以 $L_{ref}$ 再参与度量和 SDF 标注。

## 4. 目标函数: 可达性 Signed Distance Field

定义基于 $d$ 的符号距离场：

$$s(x;\mathcal{M}) := \begin{cases} +dist(x, \partial\mathcal{R}(\mathcal{M})), & x \in \mathcal{R}(\mathcal{M}) \\ -dist(x, \partial\mathcal{R}(\mathcal{M})), & x \notin \mathcal{R}(\mathcal{M}) \end{cases}$$


其中 $dist(\cdot, \partial\mathcal{R})$ 为到边界的最小距离（由 $d$ 诱导）。

**训练监督策略**: 不追求全局精确 $dist$，而是通过 Oracle 驱动的边界邻域样本构造严格、可复现的局部监督 。

**重要约束**: Eikonal 正则仅在该局部邻域成立，远场样本只参与符号约束。

## 5. 总体网络设计 (形态条件化隐式场)

### 5.1 输入

- **查询位姿**: $x=(p,R)$，以 $z(x)=[p;\xi]$ 编码 。
    
- **形态**: $\mathcal{M}$ 表示为运动学树图 $G=(V,E)$ 。
    

### 5.2 形态编码器: Graph Transformer

对图 $G$ 进行编码 ：

- **节点特征** (每个关节/连杆): 关节类型、关节轴、父子变换、连杆长度代理、关节限位区间 。
    
- **边特征**: 父子关系与相对变换 。
    
- **输出**: 全局形态嵌入 $m \in \mathbb{R}^{d_m}$ 。
    

### 5.3 位姿编码器

用 MLP 将 $z(x) \in \mathbb{R}^{6}$ 映射为位姿隐变量 $h \in \mathbb{R}^{d_h}$（推荐使用正弦特征增强高频表达）。

### 5.4 解码器: FiLM-SIREN 隐式场

采用 SIREN 风格隐式网络 $f_{\theta}$ 输出标量距离：

$$\hat{s}_{\theta}(x;\mathcal{M}) = f_{\theta}(z(x); \text{FiLM}(m))$$


其中 $\text{FiLM}(m)$ 为由形态嵌入生成的逐层缩放/平移参数，用于实现跨形态共享一个隐式场族 。

## 6. 样本采集方案 (从 FK 正样本出发，构造边界邻域 + 正负样本全覆盖)

核心原则：SDF 学边界，最有效信息来自边界邻域。样本分为三类：

1. **FK 正样本池** (可达内部): 提供 Anchor 与覆盖 。
    
2. **边界邻域样本** (主训练数据): 通过 Ray Shooting + Bisection 得到 $s=0$ 与 $\pm\delta$ 的严格监督 。
    
3. **远场负样本** (稳定训练): 覆盖位置远场与姿态远场 。
    

### 6.1 第一步: FK 正样本池 $\mathcal{A}^{+}$

在 $\mathcal{Q}_{lim}$ 中按固定分布 $\pi(q)$ 采样关节构型 $q$：

- 计算 $x = FK_{\mathcal{M}}(q)$ 。
    
- 若 $SC(q)=1$，则将 $(x,q)$ 加入正样本池 。
    
    $$\mathcal{A}^{+} := \{(x_i, q_i)\}_{i=1}^{N_{+}}, \quad x_i \in \mathcal{R}(\mathcal{M})$$
    

### 6.2 第二步: 用于边界搜索的 Anchor 选择 $\mathcal{A}_{bnd}^{+}$

从 $\mathcal{A}^{+}$ 中选择子集用于边界搜索（避免在深内部浪费算力），策略定死为“覆盖+边界偏置”：

- **覆盖约束**: 在位置空间 $p$ 做体素下采样，在姿态空间做分桶 。
    
- 边界偏置: 优先采样关节裕度小、接近限位或接近奇异的构型 。

    - 接近限位: 使用关节裕度（距上/下限的最小值）。
    - 接近奇异: 使用 Jacobian condition number 或 manipulability 指标。
    
    $$\mathcal{A}_{bnd}^{+} \subset \mathcal{A}^{+}$$
### 6.3 第三步: 边界邻域样本 (Ray Shooting + Bracketing + Bisection)

#### 6.3.1 6D 方向空间与归一化

对每个 Anchor $x_0 \in \mathcal{A}_{bnd}^{+}$，采样 $K$ 个 6D 方向 $u_k \in \mathbb{R}^{6}$，并按度量归一化：

$$||u||_{\lambda}^2 := ||u_p||_2^2 + \frac{1}{\lambda^2}||u_{\xi}||_2^2 = 1, \quad u=\begin{bmatrix} u_p \\ u_{\xi} \end{bmatrix}$$


**方向组成**:

- 少量轴向方向 ($\pm e_i$) 用于基础覆盖。
    
- 主要采用随机各向同性方向（在 $\mathbb{R}^6$ 采样后按 $||\cdot||_{\lambda}$ 归一化）。
    

#### 6.3.2 射线参数化 (在 $SE(3)$ 中的组合)

沿方向定义射线 $x(t) = x_0 \oplus (tu), t \ge 0$ ：

- $p(t) = p_0 + t u_p$ 
    
- $R(t) = R_0 \exp(t [u_{\xi}]_{\times})$ 
    

#### 6.3.3 边界定位与邻域监督标签

用 Oracle $\mathcal{O}(x(t);\mathcal{M})$ 沿射线寻找从可达到不可达的首次翻转点 $t^*$（通过 Bracket + 二分法，收敛至精度 $\varepsilon$）。

固定一个小偏移 $\delta > 0$，构造一对近边界样本：

- $x_{in} = x(t^* - \delta), \quad y_{in} = +\delta$ 
    
- $x_{out} = x(t^* + \delta), \quad y_{out} = -\delta$ 
    
- (可选) 边界点: $x_b = x(t^*), \quad y_b = 0$ 
    

这些样本构成主训练集 $\mathcal{D}_{nb}$。

### 6.4 第四步: 姿态远场负样本

为覆盖“位置可达但姿态不可达”的区域：

- 从 $\mathcal{A}^{+}$ 选取一批位置点 $p$ 。
    
- 在固定 $p$ 下，采样大量 $R \sim \text{Uniform}(SO(3))$ 形成 $x=(p,R)$ 。
    
- 用 Oracle 判定：若不可达则加入负样本集合 $\mathcal{D}_{rot-far}^{-}$ 。
    

$$\mathcal{D}_{rot-far}^{-} := \{(x,y) \mid \mathcal{O}(x;\mathcal{M})=0, p \in \text{Proj}_p(\mathcal{R}), R \sim \text{Uniform}(SO(3))\}$$


### 6.5 第五步: 位置远场负样本

从工作空间外部的包围区域（例如 AABB 外扩）采样位置 $p$，姿态随机，得到 $x=(p,R)$。

$$\mathcal{D}_{pos-far}^{-} := \{(x,y) \mid p \in \text{空间外部远场区域}\}$$


### 6.6 数据集组成与比例 (训练输入定死)

训练数据由三部分构成：

$$\mathcal{D} = \mathcal{D}_{nb} \cup \mathcal{D}_{rot-far}^{-} \cup \mathcal{D}_{pos-far}^{-}$$


- $\mathcal{D}_{nb}$: 提供最关键的边界几何与 $\pm\delta$ 距离监督。
    
- $\mathcal{D}_{rot-far}^{-}$: 保证姿态不可达区域被覆盖。
    
- $\mathcal{D}_{pos-far}^{-}$: 提供远场负约束。

## 7. 训练目标

### 7.1 边界邻域回归损失 (主损失)

对 $(x,y) \in \mathcal{D}_{nb}$：

$$\mathcal{L}_{nb} = \mathbb{E}_{(x,y)\sim\mathcal{D}_{nb}} [l(\hat{s}_{\theta}(x;\mathcal{M}), y)]$$
其中 $l$ 取 $L_1$ 或 Huber。

### 7.2 零等值面约束

$$\mathcal{L}_{0} = \mathbb{E}_{x_b} [|\hat{s}_{\theta}(x_b;\mathcal{M})|]$$
### 7.3 远场负样本约束 (Margin)

对 $x \in \mathcal{D}_{rot-far}^{-} \cup \mathcal{D}_{pos-far}^{-}$，使用 Margin 约束：

$$\mathcal{L}_{far} = \mathbb{E}_{x \sim \mathcal{D}_{far}^{-}} [\max(0, \hat{s}_{\theta}(x;\mathcal{M}) + m)]$$

其中 $m > 0$ 为固定负 Margin，默认 **$m = 0.02$** 。


### 7.4 Eikonal 正则 (仅在边界邻域使用)

在 $\mathcal{D}_{nb}$ 邻域约束距离场梯度：

$$\mathcal{L}_{eik} = \mathbb{E}_{x \sim \mathcal{D}_{nb}} [(||\nabla_{x}\hat{s}_{\theta}(x;\mathcal{M})||_2 - 1)^2]$$

_注意_: Eikonal 只在“距离语义成立”的邻域（即由 Bisection 构造的局部距离监督区域）使用 。


### 7.5 总损失

$$\mathcal{L} = \mathcal{L}_{nb} + \alpha\mathcal{L}_{0} + \beta\mathcal{L}_{far} + \gamma\mathcal{L}_{eik}$$


其中 $\alpha, \beta, \gamma$ 为固定超参数。

## 8. 推理阶段

对不可达点（$\hat{s}_{\theta} < 0$）可通过梯度下降/投影思想将其拉回 $\hat{s}_{\theta} \ge 0$ 区域 。

任务阶段差异（偏位置或偏姿态）通过推理阶段的预条件矩阵/步长权重实现，而不是通过改变 SDF 定义实现 。

**建议的终止条件**：

- $\hat{s}_{\theta} \ge 0$；
- 或 $|\Delta \hat{s}_{\theta}| < \tau$；
- 或达到最大迭代步数 $T_{max}$。

## 9. 固定超参数与记录项

### 9.1 度量与阈值

1. **长度-角度权重 $\lambda$**:
    
    - **默认**: $\lambda = 0.15$ (normalized length)/rad 。
        
    - **消融范围**: $\{0.05, 0.10, 0.15, 0.30\}$ 。
        
2. **边界二分精度 $\varepsilon$**:
    
    - **默认**: $\varepsilon = 1 \times 10^{-3}$ 。
        
    - **消融范围**: $\{5\times 10^{-4}, 1\times 10^{-3}, 2\times 10^{-3}\}$ 。
        
3. **边界邻域偏移 $\delta$**:
    
    - **默认**: $\delta = 5\varepsilon$ (即 $5 \times 10^{-3}$) 。
        
    - **消融范围**: $\delta/\varepsilon \in \{2, 5, 10\}$ 。
        
4. **远场负样本 Margin $m$**:
    
    - **默认**: $m = 0.02$ 。
        
    - (消融) 定值回归 $s_{far}=0.05$ 。
        

### 9.2 边界搜索与方向采样

1. **每个 Anchor 的方向数 $K$**:
    
    - **默认**: $K=32$ 。
        
    - **组成**: 轴向占 25% (8条)，随机各向同性占 75% (24条) 。
        
    - **消融范围**: $\{16, 32, 64\}$ 。
        
2. **括区最大尺度 $t_{max}$**:
    
    - **默认**: $t_{max} = 0.30$ 。
        

### 9.3 远场负样本规模

1. **姿态远场负样本**:
    
    - 每个位置采样姿态数 $N_R = 128$ 。
        
    - 消融范围: $\{64, 128, 256\}$ 。
        
2. **位置远场负样本**:
    
    - 默认: $2 \times 10^6$ 个样本 。
        
    - 区域: AABB 外扩 1.5 倍 。
        

### 9.4 Oracle (IK+限位+自碰) 的固定预算 (Tiered Oracle)

为降低成本并保证严谨性，采用分级预算 ：

| **Tier**   | **用途**          | **N_seed (初值数)** | **N_iter (迭代数)** |
| ---------- | --------------- | ---------------- | ---------------- |
| **Tier-1** | 粗筛 / Bracketing | 4                | 80               |
| **Tier-2** | 中精 / 二分前半程      | 16               | 150              |
| **Tier-3** | 精标 / 二分后半程与最终判别 | 64               | 200              |

Oracle 判定规则: 在任一 Tier 下，若存在任一初值在预算内满足“IK 解 + 限位内 + 不自碰”，则返回 1；否则返回 0 。

关键约束: 数据集监督标签的真值一律由 Tier-3 输出确定 。

### 9.5 训练超参数 (固定)

- **损失权重**: $\alpha=1, \beta=0.5, \gamma=0.1$ 。
    
- **训练 Batch 组成**:
    
    - $\mathcal{D}_{nb}$: 70% 。
        
    - $\mathcal{D}_{rot-far}^{-}$: 20% 。
        
    - $\mathcal{D}_{pos-far}^{-}$: 10% 。
        
- **注意**: Eikonal 仅作用于 $\mathcal{D}_{nb}$ 。
