【重要指令：MCFP 仓库代码规范（最新版）】

从现在开始，在本对话中你帮我写的所有代码，都必须符合下面这套既定约束。请不要自己随意更改整体架构或规范。

=====================================================
一、整体仓库结构（已固定，不可更改）
=====================================================

项目名：MCFP（Morphology-Conditioned Feasibility Prior）
Python 包根目录：mcfp/

目录结构如下（固定）：

- mcfp/sim/       # 仿真与物理指标计算（FK/IK、碰撞、自碰、指标、网格聚合）
- mcfp/data/      # 数据集、DataLoader、数据 I/O
- mcfp/models/    # EGNN 构型编码、PoseEncoder、主网络 F、多头 heads
- mcfp/utils/     # logging、配置、随机种子、SE3 工具
- mcfp/viz/       # 能力图、训练曲线、可视化工具

- scripts/        # 高层入口脚本（generate_data.py, train_stage1.py, eval_stage1.py 等）
- configs/        # YAML 配置文件（data_gen.yaml, train_stage1.yaml）
- env/            # conda / docker 环境定义
- tests/          # 单元测试（至少保证核心模块能 import + run）

=====================================================
二、代码放置规范（功能对应模块位置）
=====================================================

以下逻辑必须放在指定模块，不得随意混写：

1）**仿真相关（你目前主写的部分）**
   mcfp/sim/ 下分文件实现：
   - robot_model.py    # URDF 解析、构型对象封装
   - fk_ik.py          # FK/IK 调用（MoveIt / Pinocchio / PyBullet）

   - pose_encoder.py

3）**数据与 I/O**
   放在 mcfp/data/：
   - datasets.py
   - io.py
   - sampling.py

4）**工具**
   放在 mcfp/utils/：

5）**脚本 scripts/**

=====================================================
五、与 MCFP 理论设计绑定的约束
=====================================================

生成训练数据（mcfp/sim/*）必须符合以下逻辑：

- 随机关节采样 → FK 得到任务空间点
- 计算多维物理指标 g_self, g_env, g_lim, g_man
- 根据综合 utility 函数 u(q) 对 cell 聚合，选择最佳姿态 q*
- 输出每个 cell 的：
    (r, x, g_self, g_env, g_lim, g_man, u)
- 输出格式必须结构清晰，可进行大规模训练

训练模型必须符合：

- EGNN: morph_graph → r_repr
- PoseEncoder: x → x_repr
- 主网络 F: concat(r_repr, x_repr) → z
- 多头 Heads: z → 各种 g_k
